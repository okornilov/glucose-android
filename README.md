# Сахар — Android-приложение для LibreLinkUp

Автономное приложение: само раз в минуту забирает показания из облака LibreView (тот же неофициальный
API, что у LibreLinkUp и Telegram-бота `libre-tg-bot`), хранит историю на телефоне (90 дней)
и показывает уведомления. Сервер не нужен.

## Возможности

- текущее значение со стрелкой тренда и временем замера; оно же — в строке состояния;
- график за день с переключением дней и статистикой (мин/макс/среднее, время в диапазоне);
- уведомления: низкий сахар (≤ порога, по умолчанию 3.8, звук будильника), высокий (> порога,
  по умолчанию 12), нет данных дольше N минут, возврат в норму; повтор каждые N минут;
- кнопки под уведомлением: «🔕 30 мин», «🔕 1 час», «🔇 До нормализации» / «До появления данных»;
- тишина на 30 мин / 1 / 2 часа;
- своя мелодия для каждого типа: низкий, высокий, нет данных, сахар в норме, данные снова поступают
  (Настройки → «Звуки уведомлений»). Звук канала Android после создания не меняется, поэтому при смене
  мелодии канал пересоздаётся под новым id — важность, вибрация и «Не беспокоить» переносятся из прежнего.

## Сборка

1. Открыть каталог в Android Studio (File → Open), дождаться синхронизации Gradle.
2. На телефоне включить режим разработчика и отладку по USB, подключить кабелем.
3. Run ▶ — приложение установится на телефон.

APK для установки файлом: Build → Build App Bundle(s) / APK(s) → Build APK(s),
результат — `app/build/outputs/apk/debug/app-debug.apk`.

## Первый запуск

1. Разрешить уведомления.
2. Настройки → учётная запись LibreLinkUp (для России регион `ru`) → «Сохранить и проверить».
3. Включить «Фоновый мониторинг» и нажать «Разрешить работу в фоне».
4. Samsung: Настройки → Батарея → Ограничения в фоновом режиме → «Приложения без спящего режима» —
   добавить «Сахар». Иначе One UI может усыплять приложение, и уведомления будут приходить с опозданием.

## Как устроен фон

Foreground service (тип `specialUse`; `dataSync` в Android 15 ограничен 6 часами в сутки) держит процесс
и постоянное уведомление, а раз в минуту его будит точный будильник `setExactAndAllowWhileIdle`.
В Doze он срабатывает так часто, только если приложению отключена оптимизация батареи.
Состояние уведомлений («отложено», «до нормализации») хранится в SharedPreferences, пароль LibreLinkUp
зашифрован ключом Android Keystore.
