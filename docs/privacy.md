# Политика конфиденциальности приложения «Сахар»

Дата вступления в силу: 21 октября 2026 г.

«Сахар» (`ru.okornilov.glucose`) — бесплатное приложение с открытым исходным кодом
([github.com/okornilov/glucose-android](https://github.com/okornilov/glucose-android)) для просмотра
показаний глюкозы из сервиса LibreLinkUp. Разработчик — частное лицо, Олег Корнилов.

**Коротко:** у разработчика нет сервера. Приложение не передаёт разработчику и третьим лицам никаких
данных — ни показаний, ни учётных данных, ни сведений об использовании. Всё хранится на вашем телефоне,
а связь идёт только с серверами LibreView компании Abbott, которыми вы уже пользуетесь через LibreLinkUp.

## Какие данные обрабатывает приложение

| Данные | Зачем | Где хранятся |
|---|---|---|
| Email и пароль LibreLinkUp | Вход в LibreView для получения показаний | Только на телефоне; пароль зашифрован ключом Android Keystore |
| Регион сервера (например, `ru`) | Выбор сервера LibreView | Только на телефоне |
| Показания глюкозы, тренд, время замера, дата запуска сенсора | Экран, график, уведомления, виджеты, отчёты | Только на телефоне, не дольше 90 дней |
| Настройки: пороги, профили, мелодии, время сводки | Работа уведомлений | Только на телефоне |
| Служебный журнал опросов (время опросов и задержки за сутки) | Проверка, что фоновый мониторинг работает | Только на телефоне, не дольше суток |

Приложение **не собирает**: местоположение, контакты, фото, номер телефона, рекламные идентификаторы,
сведения о других приложениях. В нём нет рекламы, аналитики, счётчиков и сборщиков отчётов об ошибках.

## Куда передаются данные

- **Серверы LibreView (Abbott):** `api.libreview.ru` для региона «Россия», `api.libreview.io` и
  `api-<регион>.libreview.io` для остальных. Туда приложение отправляет ваш email и пароль при входе
  и получает показания — так же, как официальное приложение LibreLinkUp. Обработка данных на стороне
  Abbott регулируется их политикой конфиденциальности. Соединение защищено (HTTPS).
- **Больше никуда.** Разработчик данные не получает и не может их увидеть.

Данные покидают телефон по вашему действию в двух случаях:
- **«Поделиться»** и **«Отправить PDF врачу»** — вы сами выбираете приложение и получателя;
- **Android Auto** — показания выводятся на экран автомобиля, к которому вы подключили телефон.

## Хранение и удаление

- Резервное копирование данных приложения в облако отключено.
- «Настройки» → «Учётная запись» → «Выйти из аккаунта» удаляет пароль и всю историю показаний.
- Удаление приложения удаляет все его данные с телефона.
- Учётная запись LibreLinkUp управляется в приложениях и на сайте Abbott; «Сахар» не может её создать или удалить.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Интернет | Получение показаний из LibreView |
| Уведомления | Тревоги о низком и высоком сахаре, «нет данных», напоминания |
| Работа в фоне (служба, точные будильники, без ограничений батареи, запуск после перезагрузки, удержание процессора) | Опрос раз в минуту, чтобы тревоги приходили вовремя, в том числе ночью |
| Вибрация | Вибрация тревог |
| Live Update (Android 16+) | Значение сахара в строке состояния и на экране блокировки |

Приложение видит, установлено ли LibreLinkUp, только чтобы открыть его по кнопке на экране входа.

## Дети

Приложение не предназначено специально для детей и не собирает данные о возрасте.
Если им пользуется родитель для наблюдения за сахаром ребёнка, показания ребёнка обрабатываются так же,
как описано выше, — только на телефоне и в LibreView.

## Медицинская оговорка

«Сахар» — не медицинское изделие. Он использует неофициальный API LibreView, который может перестать
работать. Не используйте приложение как единственный источник решений о лечении и единственную защиту
от низкого сахара. Проект не связан с Abbott; FreeStyle Libre, LibreLink, LibreLinkUp и LibreView —
товарные знаки Abbott.
